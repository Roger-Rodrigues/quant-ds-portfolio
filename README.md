## Quantitative Research & Data Science Portfolio
Bem-vindo ao meu portfólio central. Este repositório documenta minha transição técnica e prática da Engenharia Mecânica Aeronáutica (ITA) para as áreas de Pesquisa Quantitativa, Ciência de Dados e Machine Learning.

### Objetivo
Centralizar códigos, algoritmos e projetos práticos focados na resolução de problemas complexos, modelagem estatística e estratégias quantitativas aplicadas ao mercado financeiro e engenharia.

### 📁 Estrutura do Repositório
/leetcode_oas: Resoluções focadas em algoritmos, otimização de tempo/espaço ($O(1)$, $O(n)$) e preparação para Online Assessments (OAs).
/projetos_quant: Simulações, backtesting de estratégias e manipulação de dados financeiros (foco em ferramentas como QuantConnect).
/ml_modelagem: Implementações práticas de aprendizado de máquina, regressões e análises estatísticas de ponta a ponta.
### Stack Tecnológico Base
Linguagens: Python, C++, SQL
Bibliotecas: Pandas, NumPy, Scikit-Learn, PyTorch
Ambiente: Miniconda, VS Code, Git
